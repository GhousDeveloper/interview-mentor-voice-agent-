## ✨ Key Features

- 🎤 **Voice-Based Interviews** — Experience interactive interviews using browser speech recognition.
- 🤖 **Interview Provider Architecture** — A provider-based structure designed to support integration with a real AI interview backend.
- 💬 **Interactive Interview Flow** — Build a more engaging interview experience through conversational interactions.
- 🎨 **Modern UI** — A polished interface with smooth animations and transitions.
- ⚡ **Fast Performance** — Powered by Vite and React.
- 📱 **Responsive Design** — A modern interface designed for different screen sizes.
- 🧩 **Reusable Components** — TypeScript-based components for maintainable development.
- 🎬 **Smooth Animations** — Framer Motion enhances interface transitions and interactions.
- 🎯 **Interview Mentor Vision** — A foundation for AI-assisted interview practice and teacher recruitment workflows.

## 🚀 Getting Started

### Prerequisites

- Node.js and npm
- Google Chrome or Microsoft Edge recommended for speech recognition

### Installation

```bash
# Clone the repository
git clone https://github.com/GhousDeveloper/interview-mentor-voice-agent-.git

# Navigate to the project
cd interview-mentor-voice-agent-

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open the local URL displayed in your terminal to launch the application.

### Production Build

```bash
npm run build
npm run preview
```

## 🔌 Connecting a Real AI Interview Backend

The project currently uses a `MockInterviewProvider`. To enable real AI-powered interview conversations, replace it with an `AIInterviewProvider` connected to your own backend.

**Integration roadmap:**

1. Implement the AI interview provider in `src/services/providers.ts`.
2. Create a server-side API endpoint to communicate with your chosen AI service.
3. Send interview context and candidate responses through the backend.
4. Return generated interview questions and responses to the frontend.
5. Handle API errors, loading states, and interview completion.

### 🔐 Security Best Practice

**Never expose private AI API keys in frontend code.** Store secrets in server-side environment variables and route AI requests through a secure backend proxy.

> **Important:** Browser speech recognition availability depends on browser support and permissions. A real AI interview experience requires the appropriate backend and AI provider integration.
